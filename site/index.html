Set up in three steps

No identity provider, no servers to run, nothing to configure per repo.

  1. Deploy

    One click puts noenv on your Cloudflare account. Create your admin passkey on the dashboard.

    WorkerD1KV

  2. Install and connect

    Install the CLI and add two lines to your shell profile.

    $ npm install -g noenv-cli export NOENV_URL=<your-url> eval "$(noenv shell zsh)"

  3. cd into a repo

    Approve the terminal with your passkey once. From then on, secrets just load.

    ~/code ❯ cd api noenv: loaded 12 secrets

Questions

Does the noenv server see my secrets?

No. Values are encrypted on your machine with the environment's public key before they are uploaded. The server and Cloudflare store only ciphertext.

What happens to my existing .env files?

noenv migrate uploads every value, reads it back to verify it, and only then offers to delete the file. It never overwrites a value your team already set.

Where does noenv run?

On your own Cloudflare account: one Worker, one D1 database, and one KV namespace. You deploy it with one click.

Which shells does noenv support?

zsh and bash on macOS and Linux. Secrets load when you cd into a git repository that noenv knows, and unload when you leave it.

How do teammates get access?

An admin sends an invite link. The teammate creates a passkey and connects their shell, and an admin shares the environment key with noenv grant.
